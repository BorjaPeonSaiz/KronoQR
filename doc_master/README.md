- [`docs/adr/`](../docs/adr/): 51 decisiones de arquitectura registradas.
- [`docs/cliente/`](../docs/cliente/): la documentación que recibe un cliente (instalación, operación, guía de RRHH, obligaciones legales), en español e inglés.
- [`docs/07-seguridad-madurez-y-amenazas.md`](../docs/07-seguridad-madurez-y-amenazas.md) y [`docs/verificacion/`](../docs/verificacion/): seguridad, madurez y la verificación pre-release.
