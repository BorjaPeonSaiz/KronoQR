## Registros de versiones cerradas

Los registros de la 2.1.0, la 2.2.0 y la 2.2.1 (tandas de verificación, re-verificación, planes y especificaciones
de corrección, lista de cambios y pendientes priorizados) se retiraron del árbol el 23-11-2026. Todos sus hallazgos
quedaron corregidos o trasladados a un plan posterior. Siguen, sin cambios, en la etiqueta
[`v2.3.1`](https://github.com/BorjaPeonSaiz/KronoQR/tree/v2.3.1/docs/verificacion), que es donde apuntan los ADR, el
doc 07 y el README cuando los citan.

Para leerlos en local: `git show v2.3.1:docs/verificacion/<fichero>`.
