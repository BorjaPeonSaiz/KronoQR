# auth

Acceso al panel de gestión: sesión, ámbitos del token y guarda de rutas (RF-ID-01, RF-ID-02).
Tarea 1.6; el segundo factor obligatorio llega en la 2.1.

y PIN (ADR-015, regla dura 12) y vive en `frontend-portal/`.
